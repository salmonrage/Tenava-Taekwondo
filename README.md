# Tenava Taekwondo | Ensimmäinen verkkosivuni

Tämä on ensimmäinen koskaan koodaamani ja suunnittelemani verkkosivu. Kyseessä on koulutehtävä, jossa ideoin ja toteutin sivuston kuvitteelliselle urheiluseuralle.
Koodissa on paljon virheitä, eikä se toimi responsiivisesti, mutta se on merkittävä ensiaskel ammatinvaihtajan matkallani.
